#Aerodynamics Relations Calculator 

An aerodynamics flow values calculator which calculates values such as Isentropic flow, Normal shock and Oblique Shock relations. Given below is description about the flows and what values are taken as inputs.

1)Isentropic Flow Relations: Isentropic flows are type of in which the entropy of the fluid remains constant and assumes ideal flow conditions. Calculates properties such as Mach number, temperature, pressure, density, and area ratio for isentropic flow.

2)Normal Shock Relations: It is a type of shock wave that occurs perpendicular to the direction of supersonic airflow, causing a sudden and significant increase in pressure, temperature, and density while abruptly decelerating the flow from supersonic to subsonic speeds within a very small area. Calculates properties such as Mach number, temperature, pressure, density, and stagnation properties across a normal shock wave.

3)Oblique Shock Relations: It is a type of shock wave that is angled relative to the direction of the incoming supersonic airflow, forming when a supersonic flow encounters a corner or wedge, causing the flow to deflect and compress suddenly. Calculates properties such as Mach number, temperature, pressure, density, and deflection angle across an oblique shock wave.

takes input values for: 

Gamma (γ): the adiabatic index
Mach number (M): the Mach number of the flow
Beta (β): the oblique shock angle (for oblique shock relations)
Delta (δ): the deflection angle (for oblique shock relations)

and the formulas used for the calculations:

1)Isentropic Flow Relations

M = Mach number
T/T0 = temperature ratio
p/p0 = pressure ratio
ρ/ρ0 = density ratio
A/A* = area ratio

2)Normal Shock Relations

M1 = upstream Mach number
M2 = downstream Mach number
T2/T1 = temperature ratio across the shock
p2/p1 = pressure ratio across the shock
ρ2/ρ1 = density ratio across the shock
T02/T01 = stagnation temperature ratio across the shock
p02/p01 = stagnation pressure ratio across the shock

3)Oblique Shock Relations

M1 = upstream Mach number
M2 = downstream Mach number
T2/T1 = temperature ratio across the shock
p2/p1 = pressure ratio across the shock
ρ2/ρ1 = density ratio across the shock
β = oblique shock angle
δ = deflection angle
